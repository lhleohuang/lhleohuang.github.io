# Lianghuan Huang's website

Open `index.html` in a web browser. The page works directly from this folder, without installation or a build step. Its styles, fonts, and icon are included locally, so the layout also works offline. The paper and theme links need an internet connection; the email links open your default email app.

To edit your homepage text and links, change `index.html`. The music icon beside the email icon opens `music.html`, which contains your classical music favorites, favorite groups, and humor links. You can also add recordings or more links there. The theme styles are in `assets/css/main.css`.

This is a standalone HTML adaptation of [Paul Le's Full Circle template](https://github.com/LeNPaul/full-circle), keeping its Bootstrap layout, Source Sans Pro typography, white background, and blue links. The original Jekyll templates have been turned into a ready-to-open page. No Jekyll installation is needed.

The original theme's MIT license is preserved in `LICENSE.md`. Bootstrap's license notice is included in its CSS file. The font license is in `assets/fonts/OFL.txt`.
